# cards-article

Custom **cards** block. Purpose: grid of article or adventure teasers linking to detail pages.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 image; cell 2 linked title and a short description.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
