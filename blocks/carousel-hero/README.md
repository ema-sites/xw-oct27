# carousel-hero

Custom **carousel** block. Purpose: rotating full-width promotional slides, each a photo with an overlapping content box.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 image; cell 2 heading, description and CTA link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
